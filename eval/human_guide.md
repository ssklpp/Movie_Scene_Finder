# 영화 장면 기억 수집 안내

영화 장면을 설명하면 어떤 영화인지 찾아 주는 검색기를 만들고 있습니다.
검색기가 실제 사람의 기억으로도 잘 찾는지 시험하려고, 기억나는 영화 장면 묘사를 모으고 있습니다.
5~10분이면 됩니다.

## 하는 일

1. 함께 보낸 **영화 목록**(`movie_list_v1.csv`)에서 본 적 있는 영화를 2~5편 고릅니다.
   서로 다른 영화일수록 좋습니다.
2. 영화마다 **기억나는 장면 하나**를 떠올려 한두 문장으로 적습니다.
3. 입력 양식(`human_v1.csv`)에 한 줄씩 적어서 돌려주세요.

| 열 | 적을 내용 |
| --- | --- |
| `writer` | 이름 대신 쓸 이니셜이나 별명 (예: `JH`) |
| `query` | 장면 묘사 |
| `title` | 그 영화 제목 (목록에 있는 한국어 또는 영어 제목) |
| `year` | 개봉 연도. 같은 제목의 영화가 여럿일 때만 적으면 됩니다 |
| `note` | 하고 싶은 말이 있으면 (비워도 됩니다) |

## 장면 묘사 쓰는 법

친구에게 "그 영화 뭐였지?" 하고 물어보듯이 쓰면 됩니다.

- **찾아보지 말고 기억나는 대로** 쓰세요. 기억이 흐릿하거나 조금 틀려도 괜찮습니다. 실제 사용자도 그렇게 검색합니다.
- **영화 제목은 묘사에 쓰지 마세요.** 제목은 `title` 열에만 적습니다.
- **배우·등장인물 이름은 되도록 빼 주세요.** "남자 주인공", "할머니"처럼 써 주시면 됩니다.
- 장소, 시간대(낮·밤), 날씨, 색깔, 인물이 하는 행동, 눈에 띄는 물건처럼 **눈에 보이던 것**을 적으면 좋습니다.
- 대사보다는 화면에 보이던 모습을 적어 주세요.

**좋은 예**
- "비 오는 밤에 가족이 계단을 한참 내려가서 물에 잠긴 집으로 돌아가는 장면"
- "꿈속에서 도시가 반으로 접혀서 하늘 위로 길이 이어지던 거"
- "기차 안에서 사람들이 좀비를 피해서 칸 사이 문을 막고 버티는 장면"

**피해 주세요**
- "기생충에서 반지하 장면" → 제목이 들어 있습니다
- "송강호가 나오는 장면" → 배우 이름만으로는 장면을 알 수 없습니다
- "재밌는 영화" → 장면 묘사가 없습니다

## 개인정보

`writer`에는 이니셜이나 별명만 적어 주세요. 적어 주신 묘사는 검색기 평가에 쓰이고, 이니셜과 묘사가
공개 GitHub 저장소에 평가 데이터로 올라갈 수 있습니다. 원하지 않으면 `note`에 적어 주세요.
